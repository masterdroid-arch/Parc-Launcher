# Trademark policy

The code in this repository is licensed under the GNU General Public License,
version 3 (`LICENSE`). That licence covers the code. It does not cover the
project's name or its visual identity.

## What is covered here

- The name **Parc** and the name **Parc Launcher** when used to identify this
  project.
- The Parc app icon, launcher icon and store icon in this repository.
- The Parc wordmark and the arc-and-hub logo used in the project's artwork.

These marks identify where the software comes from.

## What you may do

- Use the code under the GPL, including commercially, and state that your build
  is **based on Parc** or **a fork of Parc**. That is honest, factual use.
- Copy and modify the source for your own build.
- Keep the name in a private build you do not distribute.

## What you must do if you distribute a modified build

- Use a **different app name** that is not confusingly similar to Parc.
- Replace the **app icon and logo** with your own artwork.
- Do not imply that your build is official, supported or endorsed by the Parc
  maintainer.
- Keep the GPL notices and the copyright notices that come with the code.

You do not need permission to make a fork. You do need to make it clear that it
is a fork. Keeping the Parc name with a different icon is not enough, because
people would reasonably think it is the same app.

## Uses that are fine without asking

- Writing about Parc, reviewing it, or comparing it with another launcher.
- Linking to this repository or to an official release.
- Showing the name and a screenshot in an article, video or package listing
  that describes Parc itself.

## Uses that need written permission

- Using the Parc name or icon as the name or icon of your own app or service.
- Using the marks in a domain name, company name or product name.
- Any use that suggests sponsorship or endorsement.

## Reporting a problem

If you see a build that uses the Parc name or icon without following this
policy, write to https://github.com/masterdroid-arch/Parc-Launcher/issues. Include a link and a screenshot if you can.

This policy may be updated as the project grows. The code licence does not
change because of it.
